# 🎨 Material 3 Tonal Palette Generator

This simple web tool generates a full **Material Design 3 tonal palette** from any base HEX color.  
It uses Google’s [@material/material-color-utilities](https://www.npmjs.com/package/@material/material-color-utilities) library to calculate the full set of tonal values (from 0 to 100).

## 🚀 How to use
1. Open the page in your browser.
2. Enter a base HEX color (for example: `#6750A4`).
3. View the generated tonal palette in a 5x grid.
4. Click on any color to copy its HEX code.
5. Download all tones as a JSON file.

## 💡 Features
- Responsive layout (works on mobile and desktop)
- Copy color codes easily
- Download full tonal palette as JSON
- Visual 5-column color grid

## 🧩 Technology
Built with:
- HTML, CSS, and JavaScript (no build tools required)
- [@material/material-color-utilities](https://www.npmjs.com/package/@material/material-color-utilities) (via ESM import)
